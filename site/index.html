Setup

Set up once, use it every day.

01

Pick the tools you use

JumpKey comes with shortcuts for Jira, Linear, Zendesk, GitHub, Stripe, Shopify, Google and more. Some ask one question, like your company's Jira address.

Jira site acme
02

Or add any page

Open a page you visit often, like your admin panel, and click Add page. JumpKey finds the ID in the link and you give it a short name.

admin.yourapp.com/users/{id}
03

Type the name and the ID

You see the link before you open it. Press Enter to go.

jira ENG-482
Less typing

Use it wherever the ID is.

Just the ID

Type or paste ENG-482 on its own. JumpKey knows it is a Jira ticket. The same goes for Stripe IDs and UPS tracking numbers.

Several at once

jira ENG-1 ENG-2 ENG-3 opens three tabs. Handy when you work through a list.

From any page

See ticket numbers in Slack or an email? Select them, right-click, and choose Open with JumpKey.

No duplicate tabs

If the page is already open, JumpKey takes you to that tab. Off until you turn it on.

On every computer

Turn on sync and your shortcuts follow your Chrome profile. To share them with a teammate, export them to a file.

Stays in your browser

No account and no JumpKey server. JumpKey never reads the pages you visit.

Install

Install from the zip.

JumpKey is not on the Chrome Web Store yet, so Chrome needs you to load it by hand. Takes about a minute. Works in Chrome, Edge, Brave and Arc.

  1. Download the zip and unzip it. You get a folder named jumpkey. Put it somewhere you won't delete it, since Chrome loads the extension from that folder.
  2. Open chrome://extensions in a new tab.
  3. Turn on Developer mode (top-right corner).
  4. Click Load unpacked and choose the jumpkey folder.
  5. A setup page opens. Add the tools you use, then press ⌘⇧K (Ctrl⇧K on Windows and Linux) and type jira ENG-482.
If the shortcut does nothing, another extension may be using it. Change it at chrome://extensions/shortcuts. To update, unzip the new version into the same folder and click the reload icon on the JumpKey card.
