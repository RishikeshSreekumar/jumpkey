    F1How it works

    A link with a blank where the ID goes.

    Most work tools put the ID right in the address. A JumpKey command is that address with the ID swapped for a variable in curly braces, plus a short keyword. Three kinds of blank cover nearly everything.

    {name}

    Required

    The value you type goes here. A command with just one of these can take several values at once and open a tab for each.

    acme.atlassian.net/browse/{ticket}jira ENG-482…/browse/ENG-482
    {name=default}

    Optional, with a default

    Used when you leave it out. Type one more value and it fills in, in the order the blanks appear.

    github.com/{repo=acme/web}/pull/{number}pr 1297…/acme/web/pull/1297pr acme/api 88…/acme/api/pull/88
    {name*}

    The rest of the line

    Takes everything you type after the keyword, spaces included. Made for searches.

    google.com/search?q={query*}g how to fold a map…?q=how%20to%20fold%20a%20map

    Template lab

    pr

    Opens

      • Values are URL-encoded. In the path, slashes are kept, so acme/api stays a path.
      • A blank in the host only takes letters, digits and hyphens.
      • Only http and https links. Up to 20 tabs at once.
      • A value with spaces goes in quotes: "two words".

      The launcher

      Opens over any page. Type a keyword and its values, see the address before you go, press Enter. With nothing typed, the commands you use most sit at the top.

      jk ⇥

      The address bar

      Type jk, press Tab, then jira ENG-482. Chrome shows where it's going in the dropdown.

      right-click

      Selected text

      Spot ticket numbers in Slack or an email? Select them, right-click, Open with JumpKey, pick the command. Each value in the selection gets a tab.

      ENG-482

      Just the ID

      Give a command a pattern and the keyword becomes optional. Paste ENG-482 and JumpKey knows it's a ticket. If two commands claim it, it lists both.

      jira ENG-1 ENG-2 ENG-3

      Several at once

      A command with one value opens a tab per value. Handy for working through a list. Up to 20 at a time.

      ⌘C → ⇥

      What you just copied

      When a command is waiting for a value, JumpKey offers your clipboard. Tab fills it in, Enter goes. Copy an ID that matches a pattern and it's offered as soon as the launcher opens.

      ⌘S

      Turn the page you're on into a command.

      Press ⌘S in the launcher, or click Add page. JumpKey opens the editor with the parts of the address that look like IDs already turned into variables, named after the word before them. Click any part to add or remove one.

      F4Privacy

      Your commands stay in your browser.

      No account and no JumpKey server. The extension makes no network requests of its own, and it doesn't read the pages you visit.

      What it asks Chrome for

      storage
      Saves your commands and settings in your browser.
      activeTab
      Reads the current tab's address when you press Add page.
      contextMenus
      Adds Open with JumpKey to the right-click menu.
      clipboardReadoptional
      Only if you turn on clipboard suggestions. Read while the launcher is open, never stored or sent.
      tabsoptional
      Only if you turn on tab switching. Used to compare the addresses of open tabs when you run a command.

      Settings

      • Right-click menuLists every command that takes exactly one value. On by default.
      • Clipboard suggestionsOffer what you last copied as the next value.
      • Switch to an open tabIf the page is already open, go to that tab instead of opening it again.
      • SyncKeep commands the same on every computer signed in to your Chrome profile. Settings and usage history stay on the device.

      To share commands with a teammate, export them to a JSON file. When they import it, they choose whether to keep their own version or take yours wherever keywords clash.

      F6Install

      Installs in about a minute.

      JumpKey isn't on the Chrome Web Store yet, so Chrome needs you to load it by hand. Works the same in Edge, Brave and Arc.

      1. Download the zip and unzip it.You get a folder named jumpkey. Keep it somewhere you won't delete it, because Chrome loads the extension from that folder.
      2. Open chrome://extensions.Paste it into the address bar.
      3. Turn on Developer mode.The switch is in the top-right corner.
      4. Click Load unpacked.Choose the jumpkey folder.
      5. Pick your tools.The setup page opens by itself. Switch on a few starters, then press ⌘⇧K and type jira ENG-482.

      To update, unzip the new version over the same folder and click the reload icon on the JumpKey card in chrome://extensions. Your commands stay.

      F7FAQ

      Questions people ask

      Is it open source?

      Yes. The code is on GitHub under the MIT license, so you can read it or build it yourself. If you'd like to support the project, there's a Buy Me a Coffee page.

      Why isn't it on the Chrome Web Store?

      It isn't listed yet. Until it is, you load it from the zip with Developer mode on. You can read every line of it on GitHub first.

      Can JumpKey see the pages I visit?

      No. It never reads page content. It reads the current tab's address only when you press Add page. If you turn on tab switching, it compares the addresses of your open tabs when you run a command, and that's all.

      Do I need an account?

      No. Commands live in your browser's storage. If you turn on sync, Chrome carries them between computers signed in to your profile using its own sync storage. There is no JumpKey server.

      What if a value has spaces in it?

      Wrap it in quotes: conf "onboarding checklist". Or write the template with {name*}, which takes the rest of the line, spaces and all.

      The shortcut does nothing.

      Another extension probably has ⌘⇧K. Open chrome://extensions/shortcuts and pick a different one for JumpKey. You can also click the JumpKey icon in the toolbar.

      How do I share commands with my team?

      Export them from the manage page to a JSON file and send it over. Your teammate imports it, sees what's new, and decides whether their own commands or yours win when keywords clash.

      Does it work in Edge, Brave or Arc?

      Yes. They run Chrome extensions, and the steps are the same: open the extensions page, turn on Developer mode, load the unpacked folder.
